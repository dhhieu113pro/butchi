# Microsoft Store submission pack — Butchi 0.1.2

This file is the release checklist and copy pack for the Microsoft Store **MSI/EXE app** submission.

## Required GitHub secrets before Store RC build

- `STORE_PUBLISHER` — exact Partner Center publisher display name.
- `WINDOWS_CERTIFICATE` — base64-encoded PFX for a CA-trusted Authenticode code-signing certificate.
- `WINDOWS_CERTIFICATE_PASSWORD` — PFX password.

The Store workflow deliberately fails if these are missing. Microsoft Store does not re-sign EXE/MSI submissions.

## Package

- Product: Butchi
- Version: 0.1.2
- Architectures: x64 and ARM64
- Installer: standalone NSIS `.exe`
- Silent install argument: `/S`
- WebView2: embedded offline installer for Store builds
- Model: downloaded by the user after app installation; it is runtime content, not an installer dependency

## Suggested Store listing

### Product name

Butchi

### Short description

Translate and rewrite selected text anywhere on Windows with a private local LLM.

### Description

Butchi is a lightweight Windows tray utility for translating and rewriting selected text without sending your text to a cloud AI service.

Select text in a browser, editor, chat app, or other supported Windows application and open Butchi with the automatic selection popover or a double-Ctrl tap. Translate or rewrite results stream as they are generated by a local GGUF model.

Butchi includes configurable translation and rewrite prompts, prompt profiles, favorite target languages, searchable local history, Copy/Replace actions, system light/dark appearance, and automatic CPU/GPU backend selection when supported by the installed build.

A GGUF model is downloaded separately after installation. Once downloaded, normal inference runs locally on the device.

### App features

- Translate selected text with a local GGUF language model.
- Rewrite text for grammar, clarity, professionalism, brevity, politeness, or simpler language.
- Double-Ctrl trigger for keyboard-selected text.
- Streaming generation so results appear immediately as the model produces them.
- Copy, replace selected text, or leave results untouched.
- Favorite target languages for one-click translation reruns.
- Editable system prompts and built-in prompt profiles.
- Searchable local history with configurable retention.
- Auto, CPU-only, or GPU-preferred inference modes when supported by the build.
- System, light, and dark themes.
- Local-first privacy: selected text and history are not sent to a cloud AI service.

## Certification notes

Suggested certification notes:

> Butchi is a tray application. On first launch, Settings opens automatically when no local GGUF model is installed. The user can download the default model from Hugging Face, then click Load model. This model download occurs after app installation and is runtime AI model content; the Store installer itself is standalone/offline. Selected text, prompts, outputs, and history are processed/stored locally and are not sent to a cloud AI service. Double-Ctrl opens Butchi for keyboard-selected text. The installer supports silent installation with `/S`.
