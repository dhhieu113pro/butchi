Privacy

Butchi is designed for local Translate and Rewrite on Windows. Selected text is not sent to a cloud AI service by Butchi.

Local processing

Selected text and generated results are processed by the GGUF model configured in Butchi through local llama.cpp inference.

Local history

Translate and Rewrite history is stored locally on your device. Retention can be configured in Settings, and local history can be deleted from the app.

Network access

Network access is used when you explicitly download a model from Hugging Face. Butchi does not require a cloud AI API for normal local generation.

Source and policy

The source code and full project privacy policy are available on GitHub: github.com/dhhieu113pro/butchi.
